# Scientific scope and interpretation limits

## Supported use

- Prioritize conserved viral sequence targets.
- Map targets to a reference annotation.
- Export targets to established host off-target tools.
- Compare candidate rankings with published evidence.
- Describe idealized reference-sequence consequences of one or two canonical cuts.

## Unsupported claims

The project cannot establish that a candidate:

- is accessible inside latent neuronal chromatin;
- will be edited at the predicted site or frequency;
- disrupts every viral genome copy;
- reaches the relevant sensory ganglia;
- avoids immune, toxic or neurological effects;
- prevents human reactivation or transmission;
- constitutes a treatment or cure.

## Why there is no single “virus-breaking simulator”

Different tools answer different questions:

- sequence scanners ask whether a target exists and is conserved;
- off-target engines ask where similar host sequences exist;
- editing predictors estimate guide activity from prior datasets;
- CRISPResso2-like tools measure outcomes from sequencing after an experiment;
- virology assays test replication, infectivity and reactivation;
- animal studies jointly test delivery, tissue distribution, efficacy and safety.

No computational layer substitutes for the next evidence layer.

## Data governance

Use public, consented and appropriately licensed data. Never commit identifiable patient sequences or private clinical data to a public repository.
