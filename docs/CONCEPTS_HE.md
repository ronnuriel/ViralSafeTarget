# מושגי יסוד

## FASTA

קובץ טקסט שמכיל את רצף ה-DNA עצמו:

```text
>reference
ATGCGT...
```

כאשר יש כמה זנים, כל רשומה היא גנום אחר. עבור pipeline השימור, הקובץ צריך להיות **מיושר**: כל העמודות מייצגות מיקום מקביל, וסימן `-` מציין gap.

## GFF3

מפת annotation שמצביעה על קואורדינטות בתוך FASTA תואם:

```text
reference  source  CDS  1000  2500  .  +  0  ID=UL30;product=DNA polymerase
```

ה-GFF לא מכיל בדרך כלל את רצף ה-DNA. הוא אומר מה נמצא בין עמדות מסוימות.

## Guide ו-PAM

עורך כמו SpCas9 משתמש ב-guide שמכוון לרצף מטרה, ודורש לידו PAM מתאים. עבור SpCas9 משתמשים לעיתים קרובות בתבנית `NGG`.

```text
[20 אותיות של רצף המטרה][NGG]
```

## Conservation

שיעור הזנים שבהם אתר מסוים קיים בדיוק. בפרויקט הנוכחי, coverage של אתר הוא אחוז הגנומים המכילים את כל 23 האותיות של protospacer + PAM ללא שינוי.

## Off-target

מיקום אחר, למשל בגנום האדם, שדומה ל-guide ועלול להיות מזוהה בטעות. דמיון טקסטואלי לבדו אינו הוכחת חיתוך; יש להביא בחשבון PAM, מיקום mismatches, סוג העורך ונתונים ניסויים.

## סימולציית חיתוך

המערכת יכולה לחשב את נקודת החיתוך הקנונית המשוערת ולתאר מחיקה בין שני אתרים. זהו שינוי מתמטי ברצף הייחוס בלבד, לא סימולציה של תא או של גוף.
