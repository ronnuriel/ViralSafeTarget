# Short project summary

ViralSafeTarget is an open, reproducible virus-first framework for prioritizing CRISPR
target hypotheses. It keeps viral population conservation, predicted host matches,
guide and gene targetability, coding-disruption hypotheses, biological evidence, and
exact-target multiplex escape robustness as separate, auditable axes. The HSV-2 case
study is computational-only and seeks independent review and experimental
collaboration; it makes no safety, efficacy, treatment, or cure claim.
