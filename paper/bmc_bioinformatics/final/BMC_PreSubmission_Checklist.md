# BMC pre-submission checklist

**STATUS: DO NOT SUBMIT**

- [x] Software Article section structure matches current BMC guidance.
- [x] Structured abstract is <=350 words.
- [x] DOCX uses double spacing, page numbers and continuous line numbers.
- [x] Tables are editable and unshaded.
- [x] Figures are separate PDF/PNG files and below 10 MB.
- [x] Numerical claims are asserted from committed sources.
- [x] Corresponding-author email and both ORCID identifiers supplied.
- [ ] Shared Affiliation 1 supplied for both authors.
- [ ] Sarel Cohen's contribution statement supplied and confirmed.
- [ ] All human-review rows resolved by named domain-qualified reviewer(s).
- [ ] Asterisks removed only for resolved claims.
- [ ] DOI minted and DOI placeholders replaced.
- [ ] Funding, competing interests, contributions and acknowledgements confirmed.
- [ ] All authors approved submission and confirmed no simultaneous submission.
- [ ] Potential reviewers independently chosen and verified by the author, if supplied.
- [ ] Final author read-through and reference-manager audit completed.
