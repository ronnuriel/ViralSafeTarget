# Contributing

1. Open an issue describing the biological or engineering question.
2. Keep computational predictions separate from experimental observations.
3. Add a unit test for coordinate, strand or parsing changes.
4. Record dataset accessions and versions; never commit large raw genomes.
5. Run `pytest` and `ruff check .` before submitting a pull request.
6. Do not add wet-lab protocols, patient data, or unsupported therapeutic claims.
